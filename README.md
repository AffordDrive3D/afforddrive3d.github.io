# AffordDrive3D project page

Static project website for **AffordDrive3D: Affordance-Aware World-Action Modeling with Spatial Understanding**.

The deployable website is in [`dist/`](dist/). It has no build step or runtime dependencies and is compatible with GitHub Pages.

## Local preview

Serve the `dist/` directory with any static file server, then open the printed local URL.

## GitHub Pages

This repository is private source storage only. GitHub Pages is not enabled, and pushing changes does not publish the website.

An inactive deployment template is saved at `deployment/pages.yml.disabled`, outside `.github/workflows/`. Enable deployment only after the site is reviewed and publication is explicitly approved.
